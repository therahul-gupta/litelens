Hey HN,

Like many of you, I find myself regularly working with local SQLite databases for development, side projects, and local app storage. But every time I needed to inspect a database, I was stuck choosing between:
1. Legacy desktop apps (like DB Browser for SQLite) that feel outdated and clunky.
2. Heavy database managers (like DBeaver or DataGrip) that take 10+ seconds to launch and consume hundreds of MBs of RAM.

So I built LiteLens: an ultra-fast, zero-config local web viewer for SQLite.

You can launch it with one command:
$ npx litelens ./path/to/database.db

What it does:
- Starts in < 150ms and auto-opens a clean, dark-mode studio at localhost:4983.
- Fast paginated data grid with live search across all columns and sorting.
- Interactive SQL Studio with Cmd+Enter keyboard execution and execution time metrics (typically 0.05ms - 0.5ms).
- Cell inspector for viewing and formatting nested JSON columns and multiline strings.
- Full schema explorer showing column types, primary keys, foreign keys, indexes, and CREATE TABLE DDL.
- 1-click export to CSV or JSON.
- Safe read-only mode (--readonly).
- If run without arguments, you can click "Load Demo Store Database" to test it instantly.

Code & README: https://github.com/your-username/litelens

I'd love your feedback, feature ideas, and suggestions!
